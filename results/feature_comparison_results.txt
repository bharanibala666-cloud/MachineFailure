Raw Sensor Features vs Physics-Informed Features
Dataset    : dataset/ai4i2020.csv
Train/Test : 80/20, stratified, random_state=42, threshold 0.5

Physics features (computed from the same 6 raw inputs):
  Power [W]       = Torque x RPM x 2pi/60
  Temp diff [K]   = Process temp - Air temp
  Strain [min*Nm] = Tool wear x Torque

NOTE: TWF/HDF/PWF/OSF/RNF are sub-failure labels known only
      AFTER a failure — using them is data leakage.

KEY FINDINGS
- Physics features raise recall 69.12% -> 77.94% and F1 77.69% -> 84.80%,
  using the SAME 6 sensor inputs and the SAME XGBoost settings.
- Missed failures: 21 -> 15  |  False alarms: 6 -> 4
- 5-fold CV F1: 72.14% -> 83.41% (the gain is not luck of one split)
- A shallow tree rediscovers the documented physical limits:
  Power ~3500 W / ~9000 W, Temp diff ~8.6 K, Strain ~11000 min*Nm.
- Failures still missed by the physics model: TWF=9, HDF=3, PWF=1
  TWF happens at a RANDOM time between 200-240 min of tool wear,
  so no model can predict it exactly.
